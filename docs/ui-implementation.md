# 第一阶段界面实现

依据 `ui-design.md` 和 `module-ui-design.md`，以会话优先布局实现统一宿主外壳。所有页面使用同一个 `AppSidebar`，仅替换右侧工作区。技术栈为 React 19、TypeScript、Vite 7、Electron 41；依赖的实际版本固定在 `pnpm-lock.yaml`。

## 已完成范围

| 区域 | 当前界面与交互 |
| --- | --- |
| 应用外壳 | 固定顶部和底部入口、中部独立滚动、侧栏折叠、分组折叠、动态模块入口、模块置顶与排序 |
| 快速打开 | Ctrl / Cmd + K、按公开名称/别名/用途查找、方向键与 Enter、Esc 关闭并恢复焦点、置顶与最近打开优先 |
| 会话 | 欢迎页、按启用模块展示的示例任务、草稿、多会话本地切换、附件名称与移除、消息展示、只读能力列表、示例工具记录和引用面板 |
| 模块管理 | 完整模块列表、搜索、版本与公开能力声明、界面级启停、启停同步导航与能力数量 |
| 知识库 | 知识库局部导航、示例文档搜索/选择/预览、空库、检索测试输入、索引入口 |
| 绘图 | 提示词、独立模型入口、比例/格式、空画布、历史区域、下载与加入项目占位 |
| 项目 | 项目局部导航、示例素材网格/列表、收藏、素材详情、笔记草稿与活动空态 |
| 翻译 | 双栏编辑器、语言选择/交换、表达风格、原文计数/清空、术语表面板、历史空态 |
| 设置 | 浅色/深色/跟随系统、基础连接与代理占位、主会话提示词、模块所属设置面板与独立连接表单 |

主题、侧栏、模块启停、分组展开、置顶与最近模块使用带 `reisa.ui.` 前缀的浏览器本地偏好。它们只属于界面预览，不替代基础配置或模块生命周期服务。会话、附件名称、模块表单、收藏和笔记只保留于当前页面进程；刷新将重置。模块页面切换不销毁本地草稿，停用时当前页面返回模块管理。

## 代码边界

- `apps/desktop/src/renderer/shell/`：宿主导航、快速切换、模块管理与设置外壳。
- `apps/desktop/src/renderer/conversation/`：主应用自己的会话视图与工具状态展示。
- `apps/desktop/src/composition/modules.ts`：唯一内置模块组合根。新模块从这里注册，宿主无需加入专属业务判断。
- `packages/module-sdk/src/index.ts`：renderer 安全的 UI 贡献与能力声明类型；只描述公开接口，不导出运行处理器。
- `ResultContainer` 按结果所有者与公开类型挂载模块可选的 `resultRenderers`；没有展示组件或读取能力时只保留引用和摘要，不自动读取文件。
- `packages/ui/src/`：基础组件、原生模态框、表单与共享主题 token。
- `modules/*/manifest.ts`、`index.ts`：公开身份、导航元数据、能力声明和页面/设置贡献。
- `modules/*/ui/`、`settings/`：模块自己的页面数据与设置表单。宿主只挂载组件，不读取这些值。
- `apps/desktop/src/main/`、`preload/`：Electron 窗口与受限桥接。renderer 无 Node 或文件系统访问接口。

`check:boundaries` 检查 renderer 导入平台 API、基础包反向依赖业务模块、宿主越过组合根和模块间直接导入等常见错误。它是工程规则检查，不是不可信代码沙箱。

## 业务占位规则

点击发送会保留用户输入，并显示 Agent/模型未连接的提示。不会生成伪造回答或工具执行。附件选择只记录文件名，不读取内容或上传。内置能力的数量代表声明数，尚未注册执行处理器；当前 Schema 只是占位结构，不能作为实际调用校验使用。

导入、索引、检索、生成、翻译、真实保存和导出均待接入，按钮显示未接入提示，或在缺少有效结果时禁用。示例会话和示例资料明确标记；资源引用只有摘要，没有伪造缩略图。没有执行过程，因此不会伪造进度、成功产物或取消运行。

设置的“应用到预览”仅保留表单选择，不修改运行配置。基础连接与凭据编辑、模块真实生命周期及配置迁移需要在下一阶段实现。

后续业务接口应放在模块自己的 `runtime/`、`contracts/` 与 `storage/` 中，并由页面与 Agent 能力共同调用。跨模块保存或发送到会话应先显示用户选择的内容，再通过公开读取/接收接口传递；当前相关操作未执行。

## 验证

- `pnpm build`：严格 TypeScript 检查、导入边界检查、renderer 与 Electron 构建。
- `pnpm test`：36 个模块的完整导航、纯工具/停用过滤、中文用途与别名搜索、置顶和最近排序。
- `pnpm test:desktop`：隐藏 Electron 窗口加载生产文件，检查页面、受限桥接、无 renderer Node 接口和加载错误。
- 浏览器交互：模块导航、会话和模块草稿保留、快速切换、模态框 Esc 与焦点返回、模块启停与能力联动、主题与窄窗口。
- 布局：七个页面检查 320、768、1024、1440 px 宽度及 540 px 低高度；正文无横向溢出，底部导航保持可见。

尚未验收真实服务连接、框架执行事件、模块激活失败、协作取消、资源读取失败及业务持久化。36 模块用例目前覆盖导航算法；更多模块的完整页面与真实生命周期需随运行层接入继续验收。
