# Reisa Studio 界面设计

版本：0.3  
日期：2026-10-02  
状态：交互原型与 UI 规范草案，待视觉方向确认后实现

本设计以 [架构设计](architecture.md) 为依据。界面以普通 Agent 会话为主入口，同时支持功能模块自己的页面和设置。原型使用示例数据与本地模拟交互，不代表已经接入模型、真实文档或模块运行层。

## 1. 设计原则

1. 会话是默认入口。用户可以直接描述任务，Agent 使用已启用模块的能力完成操作。
2. 能力自然出现。工具调用作为消息的一部分展示，不单独建立常驻调度控制台。
3. 模块有独立空间。专业操作、私有数据和模块设置由所属模块的界面呈现。
4. 宿主提供统一外壳。导航、工作区、设置入口、基础组件和结果展示扩展位置由主应用管理。
5. 界面遵守数据边界。主会话只显示已经通过能力接口返回的内容，不自动加载模块数据库或私有文件。
6. 全量能力保持一致。会话显示能力数量和只读列表；模块启用与停用是应用级操作，不提供会话内的工具筛选或工具子集。
7. 不增加最大步骤数、运行时间上限、费用预算等设置。取消按钮由用户主动操作，信号交给 Agent 框架和模块处理。

## 2. 视觉方向

以低对比的中性界面作为基础，使用克制的紫色强调主操作和选中状态。避免功能模块各用一套强烈的颜色，也避免在主界面堆积能力统计卡片。

原型包含两个可比较的布局：

| 方案 | 布局 | 适用情况 |
| --- | --- | --- |
| 会话优先（建议默认） | 展开侧栏、单列会话、按需结果面板 | 日常对话、阅读和跨模块任务 |
| 紧凑工作台 | 图标侧栏、顶部工作区入口、会话与产物并列 | 桌面空间较大、频繁查看产物 |

两个方案共享模块、设置和调用规则，只在空间分配上有区别。两个原型均支持通过页头左上角按钮手动展开或收起侧栏，紧凑工作台默认收起。最终实现可采用一个默认布局与可收起侧栏、可开关结果面板，无需维护两套业务页面。

## 3. 信息架构

```text
应用外壳
├── 新建会话
├── 会话
│   ├── 最近会话
│   ├── 消息与工具执行记录
│   └── 本次明确返回的产物
├── 模块管理
│   ├── 启用 / 停用
│   └── 公开能力列表
├── 模块工作区（按注册与启用状态出现）
│   ├── 知识库
│   ├── 绘图
│   └── 项目
└── 设置
    ├── 基础配置
    ├── 会话
    └── 模块自己提供的设置面板
```

没有独立 UI 的工具模块不出现工作区入口，但仍可在模块管理页查看和启停。停用后移除工作区入口及公开能力，不删除私有数据。

## 4. 桌面布局

### 4.1 应用外壳

- 左侧导航宽度建议 200–220 px；收起后为 58–66 px。
- 顶部工具栏高度建议 60–68 px，包含当前位置、会话模型与能力入口。
- 会话正文保持适合阅读的宽度，建议上限 760 px。
- 结果面板按需打开，建议宽度 240–320 px。
- 输入区位于会话底部，与正文采用一致的阅读宽度。
- 模块自己的专业页面可使用工作区全宽，不受会话阅读宽度限制。
- 主会话和各模块共用宿主的 `AppSidebar`。品牌区、全局导航、工作空间、最近会话、底部设置与个人空间保持一致；模块局部导航位于统一侧栏右侧。侧栏展开或收起状态属于宿主，不因进入模块而改变。详见 [独立模块工作空间设计](module-ui-design.md)。

收起样式采用 58 px 图标栏：只显示 R 品牌标识、全局导航图标、模块图标、设置及空间头像；隐藏品牌文字、导航名称、数量和最近会话列表。当前页面仍使用紫色浅底高亮，图标按钮保留可访问名称及悬停/聚焦提示。右侧工作区获得释放的宽度，模块自己的局部导航不随全局侧栏一起折叠。

页头左上角的“收起侧栏 / 展开侧栏”按钮在主会话和各模块中位置一致。切换只调整侧栏和工作区布局，保留输入内容、模块选中状态和当前任务；用户选择由宿主保存。可用宽度不超过 680 px 时自动收起，按钮提示自动收起状态；恢复宽度后重新采用用户先前的展开偏好。原型已提供此交互，长列表滚动和快速打开仍按下节待实现。

正式桌面应用中，窗口外壳可以占满可用高度，消息区独立滚动、输入区保持可见。原型为了适应会话内预览采用内容自然展开，不将预览页的滚动方式直接作为生产规范。

### 4.2 宽度适配

| 可用宽度 | 布局行为 |
| --- | --- |
| ≥ 1200 px | 展开导航，可并列打开结果面板 |
| 900–1199 px | 正文优先，结果面板根据剩余宽度并列或转为上下布局 |
| 680–899 px | 缩减导航，结果面板改为抽屉或独立查看 |
| < 680 px | 图标导航、单列页面、模块卡片与表单纵向排列 |

原型额外支持 320 px 宽度以检查重排。实际 Electron 窗口的最小尺寸需要在实现阶段确定；不能靠缩小字体解决空间不足。

### 4.3 长侧栏与快速打开模块

正式桌面应用的侧栏占满宿主窗口可用高度，分成三个区域：

| 区域 | 内容 | 高度不足时的行为 |
| --- | --- | --- |
| 顶部 | 品牌、新建会话、会话、模块管理、打开模块 | 保持可见，不跟随模块列表滚动 |
| 中部 | 工作空间模块列表、最近会话 | 共享一个纵向滚动区域，内容超出时出现原生滚动条 |
| 底部 | 设置、个人空间 | 保持可见，不被长列表挤出窗口 |

中部使用可收缩的布局区域，关键约束为 `flex: 1`、`min-height: 0`、`overflow-y: auto`。滚轮和触控板在该区域内滚动，键盘聚焦的导航项保持可见；滚到边界时不带动右侧模块业务区。采用原生滚动条，系统隐藏滚动条时，仍可通过滚轮、触控板和键盘访问完整列表。

工作空间和最近会话的分组标题支持折叠。宿主记录用户的分组展开状态及侧栏滚动位置；切换页面时保留位置，不因右侧刷新跳回顶部。通过快捷入口跳转到模块时，将对应导航项滚入可见范围。收起为图标栏后沿用同一套滚动区域，底部入口仍保持可见。

同时提供以下快速入口：

1. **打开模块**：固定在顶部全局导航区，展开侧栏显示文字与快捷键，收起后显示带名称和提示的搜索图标。
2. **模块快速切换器**：`Ctrl + K`（macOS 为 `Cmd + K`）打开搜索面板；按模块名称、公开别名或用途关键词检索已启用且提供 UI 的模块。上下方向键选择、Enter 打开、Esc 关闭并返回原触发位置；中文输入法组合期间不将 Enter 当成确认操作。触控用户可以点击“打开模块”。
3. **置顶模块**：用户可以将常用模块置顶并调整顺序，仍然保留完整模块列表。置顶只影响导航位置，不重复显示同一个模块。未输入搜索词时，快速切换器优先展示置顶与最近打开的模块，再展示其他模块。
4. **模块管理**：保留可搜索的完整管理列表，用于查看、启用或停用模块；启用且有 UI 的模块可以直接打开工作空间。

快速切换器负责页面导航，不执行模块能力、不向 Agent 发送消息。它只读取模块公开导航元数据；不搜索模块文档、项目附件、翻译历史或私有配置。没有独立 UI 的模块不出现在页面切换结果中。导航检索与置顶不影响提供给模型的全量已启用能力。

宿主按稳定模块 ID 保存置顶、排序、最近打开记录和滚动状态。模块停用或移除后，移除其可打开入口；用户偏好可以按 ID 保留，重新启用时恢复。结果为空时显示“没有匹配的模块”，可清空查询或进入模块管理；点击前再次确认模块仍可用，避免打开过期结果。

实现验收需要增加 30 个以上模块及低高度窗口的场景：末尾模块可通过滚动与键盘到达；顶部和底部入口始终可见；快速搜索可打开目标页面；折叠侧栏、切换页面、模块停用和中文输入法场景行为一致。

当前会话内原型仍采用内容自然展开，仅展示少量示例模块，尚未实现受窗口高度约束的侧栏滚动、快速切换器和置顶交互。本节是正式应用的设计规范，不能将现有原型当作这些交互的实现或验收结果。

## 5. 会话页面

### 5.1 顶部

- 显示会话名称。
- 模型选择器只改变主会话使用的模型，不修改绘图等模块自己的模型设置。
- “能力 N”打开公开能力列表，展示工具名称、用途和所属模块。
- 列表只展示接口描述，不读取模块内容，也不提供逐工具开关。

### 5.2 新建会话

显示简短欢迎语和少量示例任务，例如整理资料、创作图片、查看项目。示例操作填入输入框，由用户确认发送。

建议任务入口跟随可用模块状态；模块停用时不继续承诺能够执行对应任务。普通文本会话在所有模块停用时仍然可用。

### 5.3 消息

- 用户消息采用浅色气泡，便于与回答区分。
- Agent 回答保留清晰的正文排版，不将整段回答包进大卡片。
- 工具调用记录放在对应回答内，默认显示动作、状态和结果摘要。
- 展开记录后可查看公开工具名称、请求参数、返回片段和错误。
- 展示来源引用时只使用接口已经返回的来源信息，不后台读取全文补充详情。

界面不展示模型内部推理过程；展示的是已经发生的公开调用与结果。

### 5.4 工具状态

| 状态 | 展示 |
| --- | --- |
| 已提出调用 / 等待执行 | 工具动作和“等待执行” |
| 执行中 | 动作、活动指示、模块提供的进度 |
| 已完成 | 完成图标和真实结果摘要 |
| 失败 | 简短错误，展开后查看公开错误详情 |
| 已取消 | 明确取消状态，不显示成功产物 |
| 模块不可用 | 标明模块已停用或发生故障 |

没有进度数据时使用不定进度状态，不伪造百分比。耗时信息如用于记录，只表示实际执行结果，不成为运行上限。

### 5.5 输入区

- 文本输入支持 Enter 发送、Shift + Enter 换行，并正确处理中文输入法组合输入。
- 添加附件时显示名称和可移除标识。用户提供的附件属于主应用本次输入，不自动进入任何模块的私有文件库。
- 运行时将发送按钮替换为停止按钮，取消交给框架处理。
- 显示全量可用能力数量；点击打开与顶部相同的只读列表。
- 不添加预算、最大步骤数、最大执行时间或会话级工具选择器。

原型中发送消息只模拟执行并返回明确标注的演示内容，不发送网络请求；文件选择只展示名称，不上传或读取文件正文。

## 6. 结果与资源展示

### 6.1 结果卡片

模块可为自己的结果类型提供展示组件，例如图片卡片、检索片段、音频转写或项目保存结果。宿主提供容器、加载及错误状态，模块定义公开结果的具体呈现。

图片卡片可展示名称、缩略预览、格式和公开的保存状态，提供“查看结果”“打开项目”等有实际能力支撑的操作。

### 6.2 结果面板

面板展示本次已经返回的内容、来源模块和公开元数据，不变成跨模块文件浏览器。打开面板不应触发未经接口授权的私有数据加载。

若工具只返回资源 ID：

1. 存在公开读取能力时，通过该能力取得内容并显示加载状态。
2. 没有读取能力时，只显示引用和摘要，不显示假缩略图。
3. 来源停用或资源删除后，显示“资源不可用”。

原型的示例宣传图表达“内容已经通过读取能力返回”的状态。初始示例会话同时标注了检索、生成、读取和保存动作。

## 7. 模块管理页

按模块显示名称、说明、内置/外部来源、版本、公开能力数量、状态和应用级启用开关。

启用模块后，全部注册能力进入会话工具集合；停用后，能力数量和导航同步更新。“查看能力”只查看该模块的公开接口，即使停用也可以展示其声明，不能因此执行调用。

正式实现中，生命周期状态与 UI 开关应一致：

- 激活中：显示“正在启用”，避免重复操作。
- 激活失败：开关恢复停用状态，并显示原因。
- 停用中：停止接收新调用，显示等待取消或资源释放。
- 已停用：导航和能力已撤销，保留数据。

第一阶段不展示插件商店、远程下载或在线更新入口。启停动作不同时执行清除数据。

## 8. 独立模块页面

模块页面由模块自身实现，宿主只提供工作区和导航挂载。

- 知识库：文档列表、索引状态、检索操作和模块设置入口。
- 绘图：画布、生成参数、模块自己的记录和结果编辑。
- 项目：项目列表、模块拥有的附件副本和项目设置。
- 翻译：本轮补充独立的双栏翻译、术语表和历史页面；未来纯工具模块仍可以没有独立页面。

模块自己的页面显示自己的数据，不意味着宿主会话也有同等访问权。UI 扩展接口不应将私有数据库或配置对象交给宿主。

原型中的模块数据均为示例；专业画布、导入和索引等操作仍需独立细化和实现。

四个模块独立使用的布局、交互、配置和数据边界见 [独立模块工作空间设计](module-ui-design.md)。专业工作区原型沿用紧凑工作台外壳。

## 9. 设置页面

设置采用左侧分组、右侧内容的结构。窄窗口时分组改为顶部可换行入口。

### 9.1 基础配置

主题、语言、公共服务连接、网络代理等约定的共享配置。后续服务商编辑应由基础服务拥有自己的界面与凭据管理。

### 9.2 会话设置

默认主会话模型、默认提示词和只读可用能力信息。不设置运行预算或工具子集。

### 9.3 模块设置

由模块自己提供表单、读取设置及执行保存。宿主只挂载组件，不能通过设置页的统一外观集中读取所有模块私有值。

需要继承的字段明确提供“继承基础配置”和“模块独立配置”；选择独立配置后再显示所属字段。例如绘图尺寸与格式属于绘图模块，知识库检索方式属于知识库模块。

保存提供明确成功、失败和未保存反馈。框架与模块设置迁移不通过 UI 隐式改变用户选择。

原型只在当前交互状态中保存示例设置，未建立真实配置持久化。

## 10. 组件与设计 Token

### 10.1 宿主与模块组件边界

| 组件 | 所有者 |
| --- | --- |
| AppShell、Navigation、WorkspaceHeader | 宿主 |
| ConversationView、MessageComposer、ToolCallRecord | 主应用 |
| ModuleManager、CapabilityList | 宿主 |
| SettingsShell、ResultContainer | 宿主 |
| ModulePage、ModuleSettingsPanel、ToolResultRenderer | 所属模块 |
| Button、Input、Select、Dialog 等基础组件 | 共享 UI 包 |

模块贡献使用稳定 ID、模块 ID 和对应组件入口注册。宿主不写针对知识库、绘图等模块的专属判断。原型为了演示交互使用静态示例数据，实现阶段必须通过模块注册协议生成入口。

### 10.2 建议 Token

- 中性背景、导航背景、内容表面、正文、次要文字、分隔线。
- 主强调色、主按钮文字、柔和选中背景。
- 成功、失败、等待等语义状态色，始终配合文本或图标。
- 4 / 8 / 12 / 16 / 24 / 32 px 间距。
- 8–10 px 控件圆角，12–16 px 内容圆角。
- 14 px 正文、12–13 px 次要说明、20–24 px 页面标题。
- 浅色与深色同时定义，默认跟随系统。

这些是设计建议，并非已选定组件库的代码 Token。正式组件需要统一样式和可访问性，不复制原型中的页面专用样式。

## 11. 可访问性与交互

- 所有图标操作有可读名称，收起导航仍可识别入口。
- 使用原生按钮、输入、选择器和键盘可操作的详情展开。
- 保留清晰焦点样式；Esc 关闭能力浮层，关闭后正式实现应恢复触发器焦点。
- 动态状态通过适当的 live region 宣告，避免逐 token 打断阅读。
- 信息不只依靠颜色，停用、失败、完成都显示文字。
- 输入法组合期间不触发 Enter 发送。
- 触摸目标建议至少 44 px；窄窗口输入字体保持可读。
- 模块停用导致当前页面撤销时，切换到模块管理并显示原因。

## 12. 原型交互与验证

原型可交互范围：

- 两种布局切换。
- 会话、模块管理、知识库、绘图、项目和设置页面切换。
- 新建会话、示例任务填入、发送演示消息与停止演示。
- 工具调用记录展开。
- 结果面板打开和关闭。
- 模块启用与停用，可用能力数量、列表和导航同步变化。
- 设置分组、继承模式、外观与本地模拟保存。
- 附件名称展示。
