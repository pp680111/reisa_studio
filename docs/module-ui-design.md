# 独立模块工作空间设计

版本：0.3  
日期：2026-10-02  
状态：独立使用界面的设计与交互原型

本设计补充 [整体界面设计](ui-design.md)，遵循 [架构设计](architecture.md) 的数据与能力边界。知识库、绘图、项目和翻译可以直接操作，不需要先发起主 Agent 会话。所有模块沿用主应用“会话优先”的可展开侧栏，模块内部根据业务采用不同布局。

原型均使用示例数据和本地模拟交互；没有连接真实模型、数据库、文档解析或索引服务。导出操作提供本地绘制的几何宣传图预览，不代表 AI 生成；实际文件保存待正式应用实现。

## 1. 共同边界

- 宿主负责统一应用侧栏、当前位置和模块页面挂载；模块负责专业页面、业务数据、私有设置和操作反馈。切换模块时只更换右侧工作空间，不重建一套应用导航。
- 直接操作和 Agent 工具调用复用模块业务服务。独立使用不需要经过主 Agent 推理。
- 模块自己的 UI 可以读取所属私有数据；这些数据不自动加入主会话或其他模块。
- 跨模块操作使用公开能力接口，并只传递本次操作选择的内容。
- “发送到会话”是明确的用户操作，展示即将发送的内容，不把整个文档库、历史记录或配置一并发送。
- 模型选择放在需要执行模型任务的模块内。绘图和翻译的模型及服务连接可以独立于主会话。
- 模块设置采用所属模块提供的面板。统一外观不意味着宿主集中读取模块私有配置。
- 每个模块可以安装、启用、停用；页面不假定其他模块必然存在。无项目接收能力时，绘图中的“加入项目”不可用并说明原因。
- 不新增执行步数、运行时长或费用预算限制。执行中的停止按钮对应用户取消。

## 2. 统一页面外壳

```text
统一应用侧栏                   模块工作空间
┌─────────────────┬────────────────────────────────────────┐
│ R Reisa Studio  │ 模块名称、局部说明、主要操作、模块设置 │
│ 你的 AI 工作空间├─────────────┬──────────────────────────┤
│ 新建会话        │ 局部导航或  │ 主要工作区               │
│ 会话            │ 参数面板    │ 文档 / 画布 / 素材 / 文本│
│ 模块管理        │             │                          │
│ 工作空间        │             │                          │
│ 知识库 / 绘图   │             │                          │
│ 项目 / 翻译     │             │                          │
│ 最近会话        │             │                          │
│ 设置            ├─────────────┴──────────────────────────┤
│ Z 个人空间      │ 所属模块的操作状态                     │
└─────────────────┴────────────────────────────────────────┘
```

左侧应用导航与主应用一致，展开时建议 200–220 px（原型为 204 px），窄窗口统一收起为 58 px。原型在可用宽度不超过 680 px 时收起；此状态属于宿主，切换页面或模块时保持一致。模块自己的局部导航建议 160–200 px；绘图参数面板建议 240–280 px。工作区可以按需要使用全宽，不强制套用主会话的阅读宽度。

模块原型默认展示收起样式，可以通过页头左上角“展开侧栏”按钮切换到完整侧栏，再通过“收起侧栏”切回。收起时保留 R 标识、导航图标、当前页面高亮、设置及头像，导航名称通过提示显示。此操作不折叠模块自己的知识库列表、绘图参数或其他局部面板，也不清空正在编辑的内容。窄窗口自动收起，恢复宽度后采用之前的用户偏好。

应用侧栏在主会话和所有模块中保持相同的品牌区、分组顺序、图标、间距、底色、选中状态及底部空间入口：

- 顶部：品牌标识、Reisa Studio、你的 AI 工作空间。
- 全局导航：新建会话、会话、模块管理。
- 工作空间：根据已启用且提供 UI 的模块动态生成，顺序由宿主统一管理。模块不能另建全局侧栏。
- 最近会话：主应用自己的会话记录。它不读取或混入模块自己的翻译历史、生成历史和项目活动。
- 底部：设置、个人空间、本地工作区。主题在全局设置中统一切换。

进入模块后，只有该模块入口显示页面选中状态；最近会话仍可访问，但不与当前模块同时显示为当前页面。全局“设置”与页面顶部的“模块设置”是不同入口，前者负责基础设置，后者由所属模块定义和读写。

导航、按钮、表单、文字层级和主题沿用整体界面规范。模块局部导航放在统一侧栏右侧，专业布局可以不同，色彩和基础交互保持一致。

### 2.1 模块数量较多时

沿用整体界面的 [长侧栏与快速打开模块规范](ui-design.md#43-长侧栏与快速打开模块)：品牌和全局导航保持在顶部，设置与个人空间保持在底部；工作空间和最近会话放在中间的独立纵向滚动区域。模块数量超过窗口高度时，完整列表仍然可达，不把底部入口挤出窗口。

全局“打开模块”入口和 `Ctrl / Cmd + K` 快速切换器可从主会话及任意模块页面使用，按公开名称、别名或用途关键词定位模块。常用模块支持置顶，快速切换器优先展示置顶和最近打开模块。侧栏收起后仍保留图标入口及滚动能力。

这些导航组件和偏好由宿主维护。模块只提供公开导航元数据，不另建私有快捷切换器；宿主不为检索导航读取模块业务数据。打开一个模块只导航到其页面，不自动执行能力或向主 Agent 分享内容。

当前模块原型展示四个模块并采用自然展开，尚未模拟长列表滚动、快速切换器或置顶。正式实现需要按整体设计的长列表与低高度窗口用例验收。

## 3. 知识库模块

### 3.1 主要任务

建立知识库、导入文档、观察索引状态、查看内容、独立检索并核对返回片段。

### 3.2 布局

- 左侧：知识库列表、文档数量、新建知识库。
- 主区顶部：当前知识库名称、导入文档、模块设置。
- 主区切换：文档 / 检索测试。
- 文档视图：文档列表与选中文档预览并列。
- 检索视图：查询输入、检索动作、返回片段与来源。

文档列表展示名称、格式、索引状态及实际片段信息。状态未返回时不虚构片段数量。窄窗口将文档预览放到列表下面。

### 3.3 交互

1. 新建知识库后进入空库，提示导入文档。
2. 导入后显示待解析、待索引、索引中、已索引或失败状态。
3. 选择文档查看正文和元数据，必要时展开索引片段。
4. “建立 / 更新索引”调用本模块索引服务，不通过主 Agent。
5. 检索测试返回本模块的结构化检索结果；点击来源定位到所属文档。
6. “复制内容”只复制用户选中的内容。
7. “发送到会话”先展示本次发送的正文或片段，再通过公开读取/导出能力将选定内容交给主应用。

新建名称需要去除首尾空格并校验非空。索引失败支持查看公开错误原因和重新执行，不能把失败标为已完成。

### 3.4 独立配置

服务连接继承方式、检索方式、索引相关配置。配置和文档都由知识库模块维护。

### 3.5 与 Agent 的关系

主 Agent 只可使用模块注册的检索、文档读取、文档列表等能力。知识库页面能查看完整文档，不意味着主 Agent 自动拥有文档正文。

原型中的导入仅记录文件名，不读取文件正文；“更新索引”仅演示状态切换。检索是在示例文本中进行匹配，不模拟真实向量检索质量。

## 4. 绘图模块

### 4.1 主要任务

直接编辑画面描述、选择绘图模型及参数、生成图片、查看历史、导出结果和显式加入项目。

### 4.2 布局

- 左侧参数面板：画面描述、绘图模型、比例、格式、生成 / 停止。
- 中间画布：当前生成结果与预览背景。
- 画布上方：结果名称和执行状态。
- 画布下方：输出尺寸、下载、加入项目。
- 历史区域：模块自己的结果选择入口。

初始没有生成结果时显示空画布与开始提示。执行期间保留上一张有效结果，展示本次生成状态，失败后不覆盖已有图片。

### 4.3 交互

1. 用户填写描述并选择模型、比例和格式。
2. 点击生成时，创建一次独立绘图任务并记录参数快照。
3. 生成期间可以停止；任务取消后保留已有结果。
4. 完成后显示图片，历史记录保存该次模型与参数。
5. 修改参数只影响下一次生成，不改变既有图片和元数据。
6. 选择历史结果可查看或显式复用参数。
7. 下载通过绘图模块读取结果后导出，无需主会话介入。
8. 加入项目时选择目标项目与素材名称，再调用公开接口完成内容传递。

画布按输出比例展示，不把不同尺寸的历史图片强行拉伸为相同比例。没有公开读取能力时，其他模块只能持有引用；绘图模块自己的页面仍可使用本模块私有读取服务。

### 4.4 跨模块保存

目标项目列表来自项目模块的公开列表能力。图片内容通过绘图模块公开读取能力取得，然后由项目添加能力接收；项目根据自身保存策略保存副本或引用。

如果项目模块不可用、读取能力缺失或保存失败，显示明确原因；不能扫描项目目录或绘图文件目录补救。每次保存关联调用标识，避免重试重复创建素材。

### 4.5 独立配置

服务连接、默认绘图模型、默认尺寸和输出格式。主会话模型切换不影响这些设置。

原型仅生成新的几何示例，并将 PNG / WebP 绘制为可查看的导出预览；实际文件保存由正式应用实现。参数变化用于展示界面反馈；正式实现必须保存每次结果的完整参数快照。

## 5. 项目模块

### 5.1 主要任务

创建项目、整理素材、编辑笔记、查看变化记录，以及明确分享选定内容。

### 5.2 布局

- 左侧：项目列表、新建项目。
- 主区顶部：项目名称与描述、局部操作、模块设置。
- 主区切换：素材 / 笔记 / 活动。
- 素材支持网格与列表布局。
- 选择素材后显示名称、来源、保存方式及操作。

项目页不自动汇总绘图、知识库等模块的全部资源。只展示项目已经拥有的副本或明确保存的引用。

### 5.3 交互

1. 新建项目后显示空素材区，可添加素材或编辑笔记。
2. 手动添加素材属于项目模块的导入操作。
3. 从其他模块接收内容必须走对应公开接口。
4. 素材可以选择、收藏、重命名并查看来源。
5. 笔记修改后明确保存，未保存时显示状态。
6. 活动仅记录项目发生的实际变化，不读取其他模块的内部日志。
7. 发送到会话先预览选择内容；只发送摘要时，不暗中读取并发送完整附件。

来源为“已保存副本”的素材不再依赖原文件继续存在。引用素材若来源停用或删除，显示不可用状态，不伪造可打开的文件。

### 5.4 独立配置

素材保存方式、项目自己的存储配置与默认行为。选择“只保留引用”不能绕过来源模块的读取能力要求。

### 5.5 能力契约补充建议

除项目列表、添加素材外，实际产品若需要 Agent 读取项目附件，应由项目模块明确注册 `project/read_asset`；需要修改笔记时可注册专门的笔记能力。这是待实现接口建议，不代表原架构中已有这些能力。

原型中的素材、笔记和活动在模块自己的本地状态中维护；手动导入只记录文件名，不上传或读取文件内容。

## 6. 翻译模块

本轮为翻译增加完整独立页面。其他未来的纯工具模块仍可以选择不提供 UI。

### 6.1 主要任务

直接输入文本，选择源语言、目标语言与表达风格，使用术语表，复制结果并按需保存翻译历史。

### 6.2 布局

- 左侧：翻译模块自己的历史、新建翻译。
- 主区：源文本与译文双栏。
- 各栏顶部：语言选择与语言交换操作。
- 源文本底部：字符数和清空；字符数用于信息展示，不作为执行预算。
- 主区底部：表达风格、翻译 / 停止、保存到历史。
- 术语表和模块设置通过独立面板打开。

窄窗口时原文与译文上下排列，保留完整输入与操作区域。

### 6.3 交互

1. 输入文本后直接翻译，不经过主 Agent。
2. 自动识别只用于源语言；目标语言需要明确选择。
3. 交换语言时同时交换原文与译文，自动源语言按实际识别结果转换。
4. 可以停止翻译，停止后保留已有有效译文。
5. 复制操作只复制当前译文。
6. 保存历史是明确操作，历史属于翻译模块，不成为主应用会话。
7. 术语表与表达风格进入本次翻译请求，不由宿主自动读取。
8. Ctrl / Cmd + Enter 触发翻译，输入法组合期间不触发。

目标语言变化后应提示当前译文尚未重新生成。重复保存可以复用同一条记录或明确创建新记录，实际实现需要定义一致行为。

### 6.4 独立配置

模块服务连接、默认模型、默认目标语言与表达风格。可以继承基础连接，也可以使用模块自己的连接。

原型提供 NOVA 示例文案的演示译文。其他输入明确提示尚未连接翻译服务，不能把预置文本伪装成实际翻译结果。

## 7. 模块设置面板

所有模块提供“模块设置”入口，位置一致。表单由所属模块定义和读写。

| 模块 | 本轮设置内容 |
| --- | --- |
| 知识库 | 连接继承方式、独立地址、检索方式 |
| 绘图 | 连接继承方式、独立地址、默认绘图模型 |
| 项目 | 保存副本或保留引用 |
| 翻译 | 连接继承方式、独立地址、默认表达风格 |

连接独立地址仅在选择独立配置时展开。保存反馈标明所属模块。Esc 关闭，键盘焦点留在面板内，关闭后返回触发位置。表单失败时保留用户输入。

首次运行、连接未配置和模块停用使用真实状态提示。原型中的默认连接名称只是展示用别名，未配置真实凭据。

## 8. 页面状态与窄窗口

### 8.1 通用状态

每个模块需要设计首次空数据、正常数据、执行中、失败、取消、连接未配置和模块不可用状态。

原型覆盖主要正常状态、空项目/空库、无检索结果、生成/翻译停止和独立设置；真实解析错误、服务商错误及运行层失败仍需实现阶段补齐。

### 8.2 响应布局

- 大窗口保持模块局部导航与主工作区并列。
- 中等宽度将知识库文档预览放到列表下面，素材网格减少列数；翻译编辑器上下排列，避免统一展开侧栏挤压语言选择与文本区。
- 小窗口将局部导航改为可换行集合，绘图参数与画布上下排列，翻译变为单列。
- 应用侧栏使用与主应用相同的收起规则；收起后保留图标、选中状态、按钮名称与提示，隐藏品牌文字、导航文字和最近会话列表。
- 内容和表单保持可读字号，不缩小整个页面。
- 绘图结果保持自身比例；空间不足时缩小预览，信息和操作另行重排。
- 所有图标按钮有名称，主题、状态同时提供文本或形状提示。

正式桌面应用可按业务设置内部滚动与固定工作栏；会话内原型采用自然展开以方便检查。

## 10. 原型与后续验收

原型提供模块切换、知识库创建/文档选择/检索测试、绘图参数/历史/生成停止/示例导出、显式加入项目、项目创建/布局/收藏/重命名/笔记、翻译/停止/语言交换/术语表/历史及所属模块设置。

统一侧栏还提供返回主会话、新建会话、最近会话、模块管理与全局设置的本地导航演示；这些宿主页面只演示导航及主题切换，完整会话交互以主应用原型为准。

已进行浏览器交互验证：检索命中和无结果、非空名称校验、空知识库和空项目、导入条目、生成与翻译取消、导出预览、跨模块副本保存、素材重命名和收藏、笔记与活动记录、语言交换和历史、模块独立设置。四个模块均检查了 1024、768 和 320 px 可用宽度，无横向溢出或脚本错误；另检查了窄窗口横向画面的文字间距及深色绘图页面。

本次侧栏修订另对比了主应用与模块原型在 1024、768 和 320 px 下的侧栏宽度、内边距、分组间距、底色、边框、品牌标识及选中导航样式，结果一致；验证了四个模块的当前位置、新建会话、最近会话、模块管理、全局主题及所属模块设置入口。切换到主会话后再返回模块，模块内已编辑内容仍保留。

收窄示例另验证了主应用两个布局及四个模块的手动展开/收起、统一 58 px 图标栏、跨页面保留侧栏选择、窄窗口自动收起及恢复宽度后的偏好还原。主会话未发送草稿和模块编辑内容在切换中保持；四个模块的展开与收起状态检查了 1024、768 px，自动收起状态检查了 320 px，未发现横向溢出或脚本错误。

实现验收重点：

- 四个模块均可直接使用，不依赖主会话已打开或主 Agent 已运行。
- 主会话和四个模块使用同一套应用侧栏；切换只改变当前位置和右侧内容，全局分组、宽度和设置位置一致。
- 私有页面数据不会因打开页面自动进入主会话。
- 跨模块保存只有明确执行动作时才发生，传递内容与预览一致。
- 页面与 Agent 工具调用使用相同业务服务。
- 单次任务的参数、结果、历史和错误关系准确。
- 停用依赖模块后，跨模块按钮正确降级。
- 无公开读取能力时，外部模块无法直接读取资源。
- 独立配置保存只修改所属模块，主会话模型保持独立。
- 导入、索引、生成、翻译与项目保存失败显示真实状态。
- 窄窗口、深色主题和键盘操作保持可用。
