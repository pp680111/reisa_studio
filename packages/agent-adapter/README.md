# @reisa/agent-adapter

Agent 框架适配层（架构设计 §4.2）。具体框架选型待定（架构设计 §15），本包先固化适配契约。

## 概念性操作

- `startConversation`：提交会话、模型配置与完整工具集合，接收框架运行事件
- `cancelConversation`：转发用户取消信号
- `toFrameworkTool`：将内部能力定义转换为框架工具，绑定能力调用入口
- `toConversationEvent`：统一文本、工具调用、结果、错误与结束事件

## 边界

- 不自行规划任务、不接管执行循环；不新增步数、时间、费用等硬限制（架构设计 §1）。
- 每次请求提供全部已启用且注册成功的能力；不实现工具检索或会话级工具子集（§6.3）。
- 保持工具调用 ID、参数、结果与消息关系；不通过解析模型自然语言模拟工具调用。
- 模型连接不支持工具调用机制时，明确显示连接不兼容，不做静默降级。

当前仅包含目录骨架与说明，无实现代码。
