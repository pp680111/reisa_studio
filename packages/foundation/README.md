# @reisa/foundation

基础服务层：提供机制，不含业务逻辑（架构设计 §3、§7、§8）。

## 计划内容

- 公共基础配置：主题、语言、代理、服务商连接与凭据引用
- 凭据服务：通过基础服务句柄使用凭据；工具定义与模型参数中不出现密钥
- 日志：不采集完整私有数据库、密钥或未公开配置
- 平台适配与作用域存储机制：连接管理、目录创建、备份；存储句柄按模块作用域发放（架构设计 §7.2）
- 配置继承规则支持：本次调用值 > 模块显式设置 > 公共默认值 > 模块内置默认值；每个字段声明是否允许覆盖（§8.2）

## 边界

- 不成为跨模块读取数据的旁路：不提供 `getDatabase(moduleId)`、全局文件枚举或私有配置查询接口。
- 不导入业务模块；基础包不依赖任何 `modules/*` 包。

当前仅包含目录骨架与说明，无实现代码。
