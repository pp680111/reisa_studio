# @reisa/module-host

模块宿主层：生命周期管理与能力注册（架构设计 §6、§10）。

## 计划内容

- 生命周期状态机：`disabled → activating → active → deactivating → disabled`，以及 `failed`
- 按内置模块清单加载，检查模块 ID、协议兼容性与启用状态
- 能力注册中心：校验能力名称、输入 Schema 与处理器；模块能力整体注册，失败时撤销并释放资源
- 能力调用入口 `invoke(capabilityId, input, invocationContext)`：定位注册、校验输入、执行处理器、转发取消与进度、统一错误结构
- 停用顺序：拒绝新调用 → 撤销注册 → 传递取消信号 → 等待处理器结束并释放资源 → 卸载 UI 贡献

## 边界

- 只提供确定性调用通道，不做推理、不筛选工具子集、不自动重试修改操作。
- 注册中心不存放模块私有数据；不提供跨模块数据库查询或全局文件枚举。
- 模块停用或未注册成功时，不属于可用能力集合——这是生命周期处理，不是相关性筛选。

当前仅包含目录骨架与说明，无实现代码。
