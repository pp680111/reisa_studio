# @reisa/module-knowledge — 知识库模块

职责：建立知识库、导入文档、索引与检索。主 Agent 只能使用本模块注册的公开能力访问文档；知识库页面可见完整文档，不代表 Agent 自动拥有文档正文（架构设计 §7.1、module-ui-design §3）。

## 规划的能力（最终契约在实现阶段确定）

- `knowledge/search`：检索知识库片段与来源
- 文档读取、文档列表等能力按实现需要注册

## UI 贡献

- 知识库工作区：库列表、文档列表 / 预览、检索测试（module-ui-design §3、§9）
- 模块设置面板：服务连接继承方式、检索方式、索引相关配置
- 工具结果展示组件：检索片段

## 数据所有权

文档、索引与知识库配置归本模块所有（`data.sqlite`、`files/`）。外部只能通过本模块注册的能力读取；“发送到会话”先展示本次发送的内容，再通过公开读取/导出能力传递。

## 目录（架构设计 §11）

- `manifest.ts`：模块身份与 UI 描述，不含私有配置值
- `contracts/`：可供调用方依赖的公开能力契约
- `runtime/`：初始化、能力注册、业务服务
- `storage/`：私有存储及迁移
- `settings/`：私有配置 Schema 和迁移
- `ui/`：页面、设置及结果组件
- `index.ts`：受控公开入口

已提供公开 UI 声明、独立工作区与模块设置表单。页面使用模块自己的本地示例状态，能力运行层、存储与真实业务操作仍待接入。
