# @reisa/module-project — 项目模块

职责：项目创建、素材整理、笔记与活动记录（module-ui-design §5）。

## 规划的能力

- 项目列表与添加素材：`project/add_asset` 接收显式传入的内容，或通过来源模块公开读取能力取得的副本
- `project/read_asset`：读取项目附件的能力为待实现建议（module-ui-design §5.5）

## UI 贡献

- 项目工作区：项目导航、素材网格 / 列表、素材详情、笔记、活动（module-ui-design §5、§9）
- 模块设置面板：素材保存方式（保存副本 / 保留引用）与项目存储配置

## 数据所有权

项目与项目附件归本模块所有。项目页只展示自己拥有的副本或明确保存的引用，不汇总其他模块资源；“只保留引用”不绕过来源模块的读取能力要求（module-ui-design §5.4）。

## 目录（架构设计 §11）

- `manifest.ts`：模块身份与 UI 描述，不含私有配置值
- `contracts/`：可供调用方依赖的公开能力契约
- `runtime/`：初始化、能力注册、业务服务
- `storage/`：私有存储及迁移
- `settings/`：私有配置 Schema 和迁移
- `ui/`：页面、设置及结果组件
- `index.ts`：受控公开入口

已提供公开 UI 声明、独立工作区与模块设置表单。页面使用模块自己的本地示例状态，能力运行层、存储与真实业务操作仍待接入。
