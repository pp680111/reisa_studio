# @reisa/module-translation — 翻译模块

职责：双栏直接翻译、语言与表达风格选择、术语表与翻译历史（module-ui-design §6）。翻译不经主 Agent；翻译历史属于本模块，不成为主应用会话。

## 规划的能力

- 翻译能力：工具契约在实现阶段确定；术语表与表达风格随请求传入，不由宿主自动读取（module-ui-design §6.3）

## UI 贡献

- 翻译工作区：源文本 / 译文双栏、语言控制、历史、术语表编辑（module-ui-design §6、§9）
- 模块设置面板：连接继承方式、默认模型、默认目标语言与表达风格

## 数据所有权

翻译历史与术语表归本模块所有；主应用侧栏的“最近会话”不混入翻译历史（module-ui-design §2）。

## 目录（架构设计 §11）

- `manifest.ts`：模块身份与 UI 描述，不含私有配置值
- `contracts/`：可供调用方依赖的公开能力契约
- `runtime/`：初始化、能力注册、业务服务
- `storage/`：私有存储及迁移
- `settings/`：私有配置 Schema 和迁移
- `ui/`：页面、设置及结果组件
- `index.ts`：受控公开入口

已提供公开 UI 声明、独立工作区与模块设置表单。页面使用模块自己的本地示例状态，能力运行层、存储与真实业务操作仍待接入。
