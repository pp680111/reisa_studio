# @reisa/module-image — 绘图模块

职责：画面描述编辑、绘图模型与参数选择、图片生成、历史与导出（module-ui-design §4）。绘图模型与服务连接独立于主会话模型设置。

## 规划的能力

- `image/generate`：生成图片，返回资源引用与摘要，或直接返回展示所需内容（架构设计 §7.3）
- `image/read`：公开读取能力；未注册时其他模块只能持有引用，不能读取内容

## UI 贡献

- 绘图工作区：参数面板、画布、历史记录、加入项目对话框（module-ui-design §4、§9）
- 模块设置面板：连接继承方式、默认绘图模型、默认尺寸与输出格式
- 工具结果展示组件：图片卡片

## 数据所有权

生成记录与图片文件归本模块所有。跨模块保存（如加入项目）必须通过本模块公开读取能力或显式传参取得内容，每次保存关联调用标识，不扫描文件目录补救（module-ui-design §4.4）。

## 目录（架构设计 §11）

- `manifest.ts`：模块身份与 UI 描述，不含私有配置值
- `contracts/`：可供调用方依赖的公开能力契约
- `runtime/`：初始化、能力注册、业务服务
- `storage/`：私有存储及迁移
- `settings/`：私有配置 Schema 和迁移
- `ui/`：页面、设置及结果组件
- `index.ts`：受控公开入口

已提供公开 UI 声明、独立工作区与模块设置表单。页面使用模块自己的本地示例状态，能力运行层、存储与真实业务操作仍待接入。
